BellowFlow

Free, open-source dictation for your Mac. Press ⌃⌥X, speak, press it again, and clean English text is typed into whatever app you are using.

Everything runs on your Mac. No account, no API key, no network access after the one-time model download, and no transcripts leave the machine. Whisper transcribes, a local language model tidies up the wording, and the result is typed for you.

Latest release: see GitHub

Install

The app is an 18 MB download. It fetches its speech and cleanup models (about 5.3 GB, once) the first time you start it.

Download BellowFlow for Apple Silicon

  1. Open the downloaded .dmg and drag BellowFlow into Applications.
  2. The first launch is blocked, because the app is not yet notarized by Apple. Open System Settings → Privacy & Security, scroll down to the message about BellowFlow, click Open Anyway, and confirm. This is a one-time step. (On macOS 15 and later, right-click → Open no longer works for unsigned apps; the terminal install below avoids the step entirely.)
  3. In the setup window, allow Microphone and Accessibility when macOS asks, and click Start.
  4. Wait for the status to read Ready while the models download. If the download is interrupted, click Start again and it resumes.
  5. Click into any text field, press ⌃⌥X, talk, and press it again.

Prefer the terminal?

This one line downloads the app, verifies its checksum, puts it in Applications, clears the Gatekeeper warning, and opens it:

curl -fsSL https://xuancongwen.github.io/bellowflow/install.sh | bash

You can read the script first. To check a manual download instead, get the .dmg.sha256 file next to the DMG on the releases page and run:

cd ~/Downloads
shasum -a 256 -c BellowFlow-1.0.0-rc.4-macOS-arm64.dmg.sha256

Requirements

MacApple Silicon (M1 or newer). Intel Macs are not supported.
macOS13 Ventura or newer
Memory16 GB minimum, 24 GB recommended. The app will not load its models on Macs with less.
DiskAbout 6 GB free for the models the app downloads on first start

Using it

  • Recording is a toggle: press ⌃⌥X to start and again to stop. Recordings stop on their own at two minutes.
  • Stay in the same window while the text is being typed.
  • Quit from the menu bar icon when you want the memory back.

Uninstall

Quit BellowFlow, drag it from Applications to the Trash, and delete ~/Library/Application Support/BellowFlow to remove the models.

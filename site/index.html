BellowFlow

Free, open-source dictation for your Mac. Press ⌃⌥Space, speak, press it again, and clean English text is typed into whatever app you are using.

Everything runs on your Mac. No account, no API key, no network access after the one-time model download, and no transcripts leave the machine. Whisper transcribes, a local language model tidies up the wording, and the result is typed for you.

Latest release: see GitHub

Install

Open Terminal (it is in Applications → Utilities), paste this line, and press Return:

curl -fsSL https://xuancongwen.github.io/bellowflow/install.sh | bash

That downloads the app (about 20 MB), checks it, puts BellowFlow in your Applications folder, and opens it. Then:

  1. In the setup window, allow Microphone and Accessibility when macOS asks, and click Start.
  2. Wait for the status to read Ready. The first start downloads the speech and cleanup models (about 5.3 GB, once); if the download is interrupted, click Start again and it resumes.
  3. Click into any text field, press ⌃⌥Space, talk, and press it again.

Release candidates are not yet notarized by Apple. The installer clears the quarantine flag for you, so you will not see the "unidentified developer" warning. If you would rather not run a script, follow the steps below instead. You can read the script first.

Install by hand

  1. Go to the releases page and download the .dmg file.
  2. Optional: download the .dmg.sha256 file next to it and check the download in Terminal: 
    cd ~/Downloads
shasum -a 256 -c BellowFlow-1.0.0-rc.2-macOS-arm64.dmg.sha256
  3. Open the .dmg and drag BellowFlow into Applications.
  4. The first time, right-click BellowFlow → Open and confirm, because the build is not notarized yet. Then follow the setup window as above.

Requirements

MacApple Silicon (M1 or newer). Intel Macs are not supported.
macOS13 Ventura or newer
Memory16 GB minimum, 24 GB recommended. The app will not load its models on Macs with less.
DiskAbout 6 GB free for the models the app downloads on first start

Using it

  • Recording is a toggle: press ⌃⌥Space to start and again to stop. Recordings stop on their own at two minutes.
  • Stay in the same window while the text is being typed.
  • Quit from the menu bar icon when you want the memory back.

Uninstall

Quit BellowFlow, drag it from Applications to the Trash, and delete ~/Library/Application Support/BellowFlow to remove the models.
